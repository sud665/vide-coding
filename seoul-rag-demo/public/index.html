01 / 질문하기

종료된 행사는 기본적으로 제외합니다. ‘이번 주말’ 같은 날짜 조건은 결과의 행사 기간을 확인해 주세요.

이 데모는 어떻게 동작하나요?
  1. 서버가 서울 공공데이터를 가져옵니다.
  2. 조건과 키워드로 관련 자료를 찾습니다.
  3. Gemini 키가 있으면 검색 근거만 전달해 답변을 만듭니다.
  4. 자료 번호를 검증하고 원문 링크를 제공합니다.

최대 3,000건을 조회하며, 검색 결과는 6건까지 표시합니다. 벡터 DB 없이 검색 기반 RAG 흐름을 시연합니다.
