STS와 샌드위치 방식은 어디가 다를까요?

샌드위치 = STT(듣기) → AI(대답 만들기) → TTS(읽기). STS는 음성을 실시간 모델이 직접 받아 말합니다.

언제 STS?

언제 샌드위치?

인식된 글을 확인·수정하거나 단계별 결과를 통제할 때. 초기 범위를 좁히기 쉽습니다.
